# FINDINGS — 方向 C Gate 0 → **前提颠覆**:GSM8K"自信错"= 标注噪声,非模型错

日期: 2026-07-31 | 数据: `results_gate0.jsonl` N=500, base=gemini-2.5-flash-lite, checker=gemini-2.5-flash

## 原计划
测"跨模型分歧能否在自洽子集里分开对/错"(Gate 0)。用户指令:**先分析"自信错 vs 真值"的差别,据差别定方案。**
→ 于是逐条拉自信错(correct=0 且 base 6采样全一致 base_disagree=0)的原始 trace 人工裁决。

## 决定性发现:7/7 自信错全是数据侧问题,模型零真错

|---|---|---|---|

**模型在无歧义题上真·自信错 = 0/500。** 总错 22:15 个被 self-consistency 抓到(base 自不自洽),
7 个"自洽错"全是 gold bug(3)或歧义(4)。cross_disagree 在这些上均值仅 0.21——**checker 多跟着"错",
因为答案其实对,gold 才是离群点**。

## 对方案的三条硬含义
1. **GSM8K 无法用来研究/评测"自信错检测"**:其残余自洽错≈标注噪声。任何验证器在此评测=追噪声;
   self-consistency 已抓住几乎所有真错,它"漏"的根本不是错。
2. **问题可反转(正密度机会)**:`自洽 + 跨模型一致 + 与 gold 不符` 恰好是**基准标注错误/歧义的探测器**,
   本 pilot 命中率 7/7。→ "用 LLM 共识审计基准 gold" 是有正密度的方向,与大家默认相反。
3. **若仍要做"自信错验证"**,必须换**真有自信错、且 gold 可信**的更难基准(MATH-hard/竞赛),
   再重跑本裁决建 taxonomy,再设计检测器。GSM8K 是错的底物。
