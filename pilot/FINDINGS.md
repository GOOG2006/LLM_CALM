# FINDINGS — 种子 B(动力学校对 / Kinetic Proofreading 用于输出验证)**判死**

日期: 2026-07-31 | 数据: GSM8K test, gpt-4o-mini, k=8 重推导 + k=8 全新对照
脚本: `offrate_pilot.py`(并发版) / 判决: `analyze.py results_n500.jsonl`

## 存在性问题(见 PILOT_PREREG.md)
从推理链中点截断、重采样续写得"脱落率" off_rate。校对能放大判别力的前提 =
**错误态脱落率 > 正确态**,且这份判别力 **超过普通 self-consistency**(闸①)。

## 结果(有效样本,功效达标)
| 指标 | 值 | 判据 |
|---|---|---|
| 有效 N | 436 (答错 40 / 答对 396) | 错误桶 40 ≥ 15 ✓ 有效 |
| AUROC[中点重推导 off_rate] | **0.801** | ≥0.65,off_rate 本身是好验证器 |
| AUROC[全新生成 disagree]（对照） | **0.844** | self-consistency 更强 |
| **闸①增益 = 重推导 − 对照** | **−0.043** | **< 0.03 → 判死** |
| 错答 off_rate 均值 / 对答 | 0.403 / 0.012 | 正确答案几乎全稳定 |
| "自洽但错"(错答却零脱落) | **15/40 = 38%** | 稳定错盆地占比 |

> Round1(N=120)欠功效作废(错误桶仅 8);Round2 用 N=500 跑,配额耗尽前落盘 436 条,
> 错误桶 40,功效达标,结论稳。

## 判死理由(两条,互相印证)

1. **闸①增益为负。** 动力学校对的唯一卖点=检查点重推导比普通重采样更能分辨对错。实测**反向**:
   检查点前缀把续写**锚回原路径**,多样性低于全新采样,AUROC 0.801 < 0.844。校对不仅无独立价值,
   反而**劣于它想取代的 self-consistency baseline**。机制清楚,非采样噪声(N=436,40 正类)。

2. **"自洽但错"再次成为主导。** 38% 错误答案零脱落——错误态是与正确态同样稳定的自洽吸引子,
   重推导落回原盆地。这与 `Agent_Trajectory_Verification` 的 AppWorld 判死(自洽但错主导)**跨域复现**:
   NL 核查 / agent 轨迹 / 数学推理,三域都撞同一堵墙。

## 跨模型复验(Gemini-2.5-flash-lite, N=250, 错28, 零 429)
| 指标 | GPT-4o-mini | Gemini-2.5-flash-lite |
|---|---|---|
| AUROC[重推导] | 0.801 | 0.889 |
| AUROC[self-consistency] | 0.844 | 0.890 |
| **闸①增益** | **−0.043** | **−0.001** |
| 自洽但错 | 38% | 21% |

> 两模型家族增益均 ≤0。Gemini 错答更不稳定(off_rate 均值 0.754,自洽但错仅 21%),
> **即便错答易脱落,检查点重推导仍零增益** → 失败根因不止"自洽但错无底物",而是
> **检查点锚定机制本身不提供 self-consistency 之外的判别力**。比单模型结论更强。

## 结论
- **种子 B 判死(跨两模型家族)。** "借生物动力学校对放大验证"这条跨学科桥,在有"自洽但错"的域上无底物;
  且检查点锚定使其**严格劣于 self-consistency**。不进 Gate 2。
- **副产物(正面但不新):** off_rate / self-consistency disagreement 在 GSM8K 上 AUROC≈0.80–0.84,
  是可用的零真值验证器——但 self-consistency 早为人知,无 ICML 新意。

## 对其余跨学科方向的外推(诚实标注)
"自洽但错"是**跨切威胁**:任何靠"扰动后看输出是否改变"的验证(含方向 B 涨落-耗散),
对那 ~38% 稳定错盆地都会失效。**下一个方向必须先证明它能对"自洽但错"子集有判别力**,
否则会第四次撞同一堵墙。→ 这应成为任何新种子的 Gate 0。
