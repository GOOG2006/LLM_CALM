# Pilot 预注册 — 种子 B：动力学校对(Kinetic Proofreading)用于输出验证

> Gate 1（存在性)。承接 LLM 输出侧验证跨学科方向分析,方向 A=动力学校对。
> **在跑任何全量数据前钉死存在性问题、判死阈值、防自欺闸**(防"自洽但错"同款证伪,见
> `Agent_Trajectory_Verification/pilot/FINDINGS_appworld.md`)。
> 预注册时间: 2026-07-31。后端: OpenAI SDK,`PILOT_MODEL` 可配,默认 gpt-4o-mini。

## 理论根
Hopfield(1974)/Ninio 动力学校对:生物用**多级不可逆丢弃检查点 + 耗能**,把错误率压到远低于
热力学平衡极限。错误率随检查点级数 n **指数下降**——**前提是错误态的脱落率(off-rate)高于正确态**。
搬到 LLM:把验证做成"从推理链中间态重推导、不一致则丢弃"的多级流程。

## 存在性问题(唯一要回答的)

> 对同一题,把参考推理链在中点截断、重采样续写 K 次,得到"脱落率"
> off_rate = P(重推导的最终答案 ≠ 参考答案)。
> **正确答案与错误答案的 off_rate 是否可分?** 用一个数衡量:
>
> **AUROC( off_rate 作为"该题答对"的预测子 )**

若不可分(AUROC≈0.5),则:错误答案是与正确答案**同样稳定的自洽吸引子**,重推导每次落回同一
自洽但错盆地 → 校对放大增益=0 → **当场判死,连 compute 对比都不跑**。这与 SMT 死于
"自洽但错=对真值求值,非对未知求解"是同一结构性死因。

## 为什么 off_rate 这一个数就够
- AUROC 高 → (1) 校对有底物(错误态确实更易脱落);(2) off_rate **本身**即一个**零真值**验证器
  (test 时不需要 gold,只需重采样)——那才是可发的论文主体。
- AUROC≈0.5 → 两件事同时死,方向 A 收尾。

## 判死阈值(预注册,不得事后改)

- **AUROC ≥ 0.65 → 底物存在**,进入 Gate 2:建分级丢弃调度器 + 匹配 compute 对比。
- **AUROC < 0.55 → 判死种子 B**,写 FINDINGS 收尾。
- **0.55 ≤ AUROC < 0.65 → 灰区**:不算过。换更难、重推导多样性更高的域(MATH)复测;仍不过 0.65 判死。

## 防自欺闸(每条结论过闸,任一不过即降级)

1. **自洽性溶解闸(核心,对标 SMT-edge 闸)**:off_rate 的判别力是否只是 vanilla self-consistency 的
   换皮?对照 = **K 次全新完整生成的答案熵**(无中点截断)。若"中点重推导 off_rate"相对该对照
   **AUROC 无显著增益** → 校对不提供 self-consistency 之外的东西,**降级**(不算方法创新,顶多是 baseline)。
   *——这一闸决定"动力学校对"是不是真有独立价值,是全 pilot 最关键的一刀。*
2. **难度混淆闸**:off_rate 差是否只是在重标注题目难度?按链长/难度分层,差必须**层内存活**。
3. **compute 闸**(仅当底物存在时才验):分级"重推导+丢弃"须在**匹配采样预算**下打过 best-of-n /
   多数投票;打不过 = 只是换了个花样的 self-consistency。

## 样本与分层

- n ≈ 60 题(默认),需正确/错误两桶各 ≥ 15 条才有效(否则加采样到够)。
- 主层:**GSM8K**(数值 gold,判对错干净,重推导易实现)。
- 副层(仅灰区时启用):**MATH**(更难、盆地更多、脱落更有戏)。
- 每题:1 条参考链(定对错) + K=8 次中点重推导 + K=8 次全新生成(对照闸①)。

## 数据获取(已验环境可得,2026-07-31)
- `datasets` 5.0 已装;GSM8K 走 `load_dataset("gsm8k","main",split="test")`,取前 n 条。
- 无 gated 依赖。gold 仅用于**测量 AUROC**,不进入 test 时验证器。

## 产出
- `pilot/offrate_pilot.py` — 本存在性测量脚本(内联注释)。
- `pilot/results.jsonl` — 每题 {id, ref_correct, off_rate_rederive, ans_entropy_fresh, chain_len}。
- `pilot/FINDINGS.md` — 两条 AUROC(重推导 / 对照) + 闸①增益 + 判死/过闸决策。
